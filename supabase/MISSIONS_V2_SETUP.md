# 90개 미션 v2 적용 및 배포

기준 자료는 `src/core/data/missions-v2.md`와 `missions-v2.json`이다. 제공받은 2026-11-08 최종안과 게임 적용 데이터 v2를 그대로 보관했다. 기존 `docs/` 명세는 수정하지 않았다.

## 적용 범위

- 일상·학업·일의 90개 미션, 사용자 선택에 따른 지원 단계, 기본·축소 행동과 조건 확인을 적용한다. 날짜나 건강 상태로 단계를 자동 변경하지 않는다.
- 사용자 확인에 따라 하루 실제 행동 완료는 최대 3개, 첫 방문 씨앗 주머니와 직접 심기는 유지한다.
- 새 미션의 완료는 자기보고다. 사진·학업 자료·업무 문서를 요구하거나 전송하지 않는다. 기존 진행 중인 구형 계획의 처리 코드는 호환성을 위해 남긴다.
- 실제 행동 기록이 있는 회차를 마칠 때 씨앗 주머니를 한 번 지급한다. 같은 회차의 추가 행동과 부모·자식 미션은 보상을 중복 지급하지 않는다. 계획 저장과 실행 전 쉬기는 지급하지 않는다. 실행 후 쉬기는 해당 회차를 정산한다.
- 직접 만들기, 원본 조건을 유지하는 복사, 다음 행동 책갈피, 하루 지도 1~3칸과 선택한 한 행동 실행을 지원한다. 저장만으로 실제 완료 기록을 만들지 않는다.
- 기존 식물·배치·가방·경제·방문 보상·스토리는 유지한다. 기존 16개 활동 ID는 과거 기록 및 진행 호환성을 위해 남긴다. 회차 보상을 받은 날짜는 기존 나무 재성장용 보상 날짜 계산에 하루 한 번 포함된다.

## 저장과 연결

`AppState.missions`에 조건, 단계, 회차, 실제 실행, 책갈피, 직접 만든 미션과 하루 지도를 저장한다. 실제 기록은 기존 `logs`에 `mission` 메타데이터를 추가한다. `decodeState`가 이를 검증하고 기존 계정 저장 스냅샷에 포함한다. 루트 저장 버전과 RPC 인자, 테이블·컬럼은 바꾸지 않는다. 구형 저장에는 새 필드를 강제로 넣지 않는다.

`src/core/missions.ts`의 `startMission`, `reportMission`, `closeMissionSession`, `restMissions`, `saveCustomMission`, `saveMyDay`, `startDayMission`, 책갈피 함수가 규칙의 연결 지점이다. `MissionPanel`, HUD, 완료 흐름과 씨앗 주머니 화면에 연결되어 있다. 계정별 로컬 분리, 서버 충돌 처리와 수동 선택 정책은 기존 구현을 따른다.

직접 쓴 행동·조건·책갈피는 진행 데이터로 저장된다. 이 내용을 console·오류 로그에 출력하지 않는다.

## 배포 순서

1. 기존 정원 저장 마이그레이션이 적용되어 있는지 확인한다.
2. Supabase SQL Editor에서 `supabase/migrations/20261109010000_preserve_mission_progress.sql`을 실행한다.
3. 이후 새 웹 버전을 배포한다.

이 SQL은 기존 `save_garden_progress`의 인증·권한·revision 충돌 검사·중복 요청 처리를 유지하면서, 새 미션 데이터가 있는 저장을 구형 브라우저가 필드 없이 덮어쓰는 요청을 거부한다. 새 테이블이나 RLS 정책은 추가하지 않는다. 구형 클라이언트는 갱신이 필요할 수 있으며 로컬 데이터는 삭제하지 않는다. 실제 Supabase에 이 SQL을 대신 실행하지 않았다.

## 검증

- Node.js 22에서 타입 검사, lint, Vitest 150개, 프로덕션 빌드를 검사한다.
- 브라우저에서 영역 건너뛰기, 조건 변경, 기본·축소, D01→D06 단계 동의, 하루 3개 제한, 회차당 주머니 하나, 저장 복원, 복귀 전 업무 차단, 직접 만들기와 하루 지도 실행을 검사한다. 인증·서버 응답은 격리된 모의 응답이며 실제 Google/운영 계정 검사와 구분한다.
- 로컬 PostgreSQL에서 기존 정원 저장 SQL 검사와 `supabase/tests/mission_progress.sql`을 실행한다. 후자는 구형 클라이언트의 필드 제거 차단과 새 저장 허용을 확인하고 rollback한다.
- 운영 SQL 적용 후 실제 계정 두 브라우저에서 정원·가방·미션·회차·책갈피 복원과 모바일 화면을 추가 확인한다. 운영 배포와 실제 기기 검사는 별도다.
