# 피오가 숨겨놓은 씨앗

사용자 요청에 따른 탐험 이스터에그. 집 왼쪽 위 꽃나무 주변(월드 820,1100)에 느낌표를 표시한다. 야외에서 84px 이내로 다가가면 기존 추첨 규칙의 씨앗 3개를 가방 씨앗함에 바로 지급한다. 주머니 3개가 아니다.

수령 여부는 기존 `garden_saves.state.garden.exploration.pioSeedsFound: true`에 저장한다. 선택 필드이므로 구버전 저장본은 미수령으로 읽는다. 기존 JSONB 계정 저장/CAS 동기화를 사용하며 새 SQL·테이블·컬럼·서버 배포는 필요 없다. 공개 정원 projection에는 이 필드를 추가하지 않는다.

게임 진행 내 수령 상태를 검사해 재접근·재접속 시 중복 지급하지 않는다. 씨앗과 수령 상태를 하나의 `store.tryUpdate`로 반영하며 로컬 영속화가 거절되면 둘 다 반영하지 않는다. 실제 서버 저장 완료 여부는 기존 SaveStatus가 표시한다. 여러 기기의 충돌은 기존 로컬/서버 선택 정책을 따르며, 별도의 서버 지급 원장이나 변조 방지 기능을 추가한 것은 아니다.

실제 활동 완료·하루 3회 상한·미션 회차·방문 보상·주머니·열매·스토리 조건은 변경하지 않는다. 모달·꾸미기·실내·다른 사용자 정원 방문 중에는 발견하지 않는다. 씨앗 종류는 기존 `drawPlant`, 씨앗 ID는 기존 `addSeed`를 사용한다.

연결: `src/core/pioSeeds.ts`(위치·수령 규칙), `src/scene/pioSeedMarker.ts`(코드로 그린 느낌표), `GardenScene`(접근 감지), `pio-seeds-found`/`pio-seeds-save-error`(내부 typed event), `ui/panels/PioSeeds.tsx`(안내와 씨앗함).

검증: 단위 테스트는 근접/실내/이상 좌표·3개 지급·중복·이전 저장 호환·수령 후 복원·활동 상한과 무관한 지급을 검사한다. 모킹한 Chrome에서는 UI 잠금, 저장 실패/재시도, 씨앗함, 서버 스냅샷과 재접속을 확인한다. 운영 Supabase의 실제 계정 테스트와는 구분한다.
