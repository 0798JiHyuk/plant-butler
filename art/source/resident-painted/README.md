# 주민 지도 새 그림 · 2026-11-15

최신 사용자 요청: 기존 맵을 분석해 위치와 그림체를 참고하되, 잘라 붙인 마스크나 추상 SVG가 아닌 새 사진/그림으로 제작한다.

- 제작: 내장 `image_gen`으로 세 이미지 각각 생성. 전체 프롬프트는 `prompts.json`에 보관한다.
- 참조: `art/source/world-hd/preview.jpg`의 전체 배치와 `art/guide/theme_a_empty.png`의 팀 A 테마. 안개는 이전 실제 지도 화면 `four-tiles-fog-before.png`를 스타일 참조로 사용했다.
- 원본: `nuri.png`, `moru.png`, `pio.png`, 각 1448×1086 RGBA. 기준 이미지나 이전 생성본을 덮어쓰지 않았다.
- 느리: 큰 나무·돌담·돌의 위치와 재질을 참고한 새 투명 배경 그림. 원본 RGB를 그대로 복제한 결과나 경계 마스킹 추출본이라고 표현하지 않는다. 생성 이미지이므로 세부 윤곽과 주변 장식에는 원본과 차이가 있다.
- 모루: 같은 월드의 길 위치와 연결을 참고해 사질감과 징검돌을 새로 그렸다. 건물 앞에서 잘린 조각 대신 자연스러운 길 끝과 연결을 사용한다. 길 찾기의 실제 판정은 기존 월드 좌표를 사용한다.
- 피오: 새로 그린 크림·세이지색 안개 재질만 사용한다. 이전의 통행 불가 지형 표시 방식은 최신 요청으로 교체됐다. 현재 미발견 영역에서만 안개를 보여주고, 발견한 장소에서는 걷힌다.
- 전체 지도·미니맵·피오 지도는 `ExplorationFog.tsx`의 같은 발견 영역 계산을 공유한다. 원본 지형을 직사각형으로 잘라서 피오 그림으로 표시하지 않는다.
- UI 프레임, 지도 공개 조건, 이름·표식 저장, 계정 진행, 경제 규칙은 유지한다. 피오 소개 문구만 실제 안개 의미와 맞춘다.
- `tools/export_resident_paintings.py`로 알파를 유지해 `public/assets/garden/resident-{nuri,moru,pio}-painted.webp`를 출력한다. `tools/slice_world_art.py`에서도 이 출력 경로를 사용한다. 이전 추출 방식은 더 이상 자동 실행하지 않는다.
