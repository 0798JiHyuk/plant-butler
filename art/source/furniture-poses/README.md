# 가구 상호작용과 지형 경계 수정 · 2026-11-15

사용자 요청의 다섯 항목: 벤치·해먹 휴식, 하단 상점 버튼 제거, 보이는 지형과 통행 동기화, 상점 프레임, 근접 상호작용.

- 내장 `image_gen`으로 `sit.png`, `lie.png`를 새로 제작했다. 참조는 현재 새싹이 원본 `sprout2-basic.webp`와 기존 벤치·해먹 이미지다. 기존 서 있는 캐릭터를 회전하거나 찌그러뜨리지 않는다. 전체 프롬프트는 `prompts.json`.
- `tools/export_furniture_poses.py`는 알파 여백만 정리하고 비율을 유지해 앉기 90×90, 눕기 112×80 게임 캔버스로 출력한다. 캐릭터 원본과 이전 포즈를 보존한다.
- 벤치는 좌판 높이와 매 프레임의 가구 앞 depth를 사용한다. 해먹은 별도 눕기 원점과 위치를 사용한다. 일어나기·꾸미기 진입 시 정상 원점·배율·자세를 복원한다. 기존 저장의 가구 ID와 휴식 자리는 유지한다.
- 배경은 `world-boundaries/sw.png`, `se.png`를 새로 편집해 기존 돌담 바깥의 낮은 덤불과 우하단 숲 경계를 보강했다. 북쪽 원본은 유지한다. 정원 출입구·건물 문·길·배치 좌표를 옮기지 않는다.
- `python tools/stitch_world_hd.py --boundaries`는 기존 북쪽 두 장과 수정 남쪽 두 장을 접합해 `world-boundaries/stitched.png`를 만든다. `python tools/slice_world_art.py`는 네 WebP와 새 포즈를 출력한다. 최신 월드 파일명은 `world-boundaries-{nw,ne,sw,se}.webp`다.
- `core/terrainBoundaries.ts`는 열린 잔디 영역, 실제 돌담의 선분, 나무 밑동을 정의한다. `worldTerrain.ts`가 이동 판정을 공유한다. 이전의 보이지 않는 정원·마당 사각형 제한은 열린 잔디에 적용하지 않는다. 씨앗·가구의 야외 배치는 여전히 왼쪽 아래 정원 안으로 제한한다.
- NPC·지도판·집·벤치·해먹·식물·상점 클릭은 가까이에서만 실행한다. 기본 240 월드 px, 건물 문/상점은 300 px. (후속 사용자 요청으로 확대) 화면의 이동 안내·기록 열람은 물리적 상호작용과 구분한다.
- 하단 상점 버튼은 제거했다. 구매 UI는 상점 문 앞 거리 검사를 통과해야 열린다. 실내 가구 창고·이야기에서 구매를 요청해도 멀리 있으면 상점 앞 이동 안내만 표시한다. 구매·미리보기에서 캐릭터를 자동 이동시키지 않는다.
- 상점 상품 목록은 프레임 내부에서 스크롤하고 제목·잔액·닫기는 고정한다. 이전 거리 안내 토스트가 제목을 덮지 않도록 상점 진입 때 닫는다.
- 보상·구매 가격·확률·로그인·SQL 스키마는 변경하지 않는다. 실제 휴대폰 검증과 배포는 별도다.

후속 입구 보정: 지도판 옆 왼쪽 돌담 충돌선을 돌의 밑면과 기둥 발에 맞추고, 그 앞 잔디가 빠져 있던 통행 영역에 `GATE_APRON`을 추가했다. 돌담을 통과하게 만들거나 기존 정원 배치 구역을 넓히지는 않는다.
