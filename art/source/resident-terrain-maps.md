# 주민 지도 표현 변경 · 2026-11-15

최신 정정: 별도로 그린 SVG 나무·돌·길과 빗금 도형은 제거했다. 현재는 [원본 배경 픽셀 추출 방식](resident-extract/README.md)을 사용한다. 아래 추상 SVG 방식은 이전 구현 기록이다.

사용자 요청: 느리는 전체 맵의 큰 나무·돌담·돌만, 모루는 길만, 피오는 새싹이가 통행할 수 없는 지형만 표시한다.

- 기존 React 지도 프레임과 SVG 렌더링을 유지한다. 지도 그림은 `src/ui/panels/ResidentTerrain.tsx`, 패널은 `ResidentMaps.tsx`다. 새 라이브러리나 이미지 생성 API는 사용하지 않는다.
- 모든 지도는 실제 월드와 같은 4096×3072 좌표를 쓴다. 느리의 나무·돌담·돌은 `world-hd/stitched.png`를 대조한 그림 좌표이며, 집·도로 그림을 넣지 않는다.
- 모루는 `WORLD_EDGES`의 통행 경로를 그린다. 건물 뒤에 가려진 연결도 게임에서 통행 가능한 우회 경로로 이어져 끊기지 않는다. 집·나무·건물 아이콘은 없다.
- 피오는 `worldTerrain.ts`의 고정 지형 판정과 건물 충돌을 사용한다. 플레이어 발 크기를 반영하고 16px 격자로 빗금을 만든다. 미발견 안개와 다르며 방문하면 없어지는 표시가 아니다. 이동 가능한 통로와 막힌 지형을 반대로 표시하지 않는다.
- 움직일 수 있는 텃밭·개별 가구·식물은 정적 경계 지도에 넣지 않는다. 개인 배치가 바뀔 때마다 주민의 지도를 다시 그리지 않는다.
- 기존 통행 판정의 코드는 순수 core로 이동하여 씬과 피오 지도가 함께 쓴다. 실제 이동·건물 충돌 규칙은 변경하지 않는다.
- 세 지도 겹쳐 보기는 지도판 홈 확인 뒤에만 유지한다. 내 지도 표식은 기존 장소 키를 유지하되 현재 월드의 해당 장소에 표시한다.
- 이번 요청은 이전 스토리 MD의 ‘피오의 소리 지도’ 설명보다 우선한다. `story-map.json`, 대응 원고 `story-map-source.md`의 지도 소개 문구와 조건부 응답만 수정한다. 피오의 소리 수집가 설정, 별도 소리 이야기, 장면 ID·선택 ID·사실 키·선행 조건·저장·보상은 유지한다.
- 보호 문서인 `docs/**`, `AGENTS.md`, `CLAUDE.md`는 수정하지 않는다. 팀 검토 시 피오의 최신 지도 역할은 이 사용자 요청과 위 변경을 기준으로 확인한다.
