# 틈새정원 · 스토리와 탐색 구현안

작성일 2026-11-14 · 제안 버전 `story-map-v2` · **구현 완료 문서가 아닌 개발 검토용 계약**

## 이번에 만들려는 경험

정원에서 작은 단서를 보고 길을 걸어 다음 장소를 발견한다. 우측 상단 지도는 **내가 있는 곳·돌아갈 길·궁금한 방향**을 알려주고, 이야기를 만날수록 내가 고른 표시가 더해진다. 현실 미션을 하지 않아도 산책하고 본편을 끝낼 수 있다.

기존 미션 90개, 씨앗 정산, 성장·구매 규칙은 이번 변경 대상이 아니다. `기존규칙_참고/04_구현_명세.json`은 공통 정책·경제·튜토리얼 참고용이고 미션은 `기존규칙_참고/01_미션_90개.json`을 유지한다. **스토리 등록 권위는 `08_스토리_개정데이터.json` 한 파일**이다. 구버전 스토리 JSON은 참고만 하고 동시 등록하지 않는다. 지도 JSON은 바로 실행되는 런타임 매니페스트가 아니라 이 콘텐츠들을 연결할 어댑터 계약이다.

기존04의 `contentFiles.story`와 ‘세 JSON 버전 동일’ 규칙은 이 패키지의 서사 로드에 적용하지 않는다. 원본 미션·정책 `2026-11-14-final-6`, 개정 스토리 `story-map-v2`, 지도 계약 `2026-11-14-story-map-v2`를 보존 ID·신규 milestone·r2 선택 ID의 명시적 호환 매핑으로 연결한다. 08의 `migration`·`contractNotice`를 우선한다.

## 1. 기능별 제작 범위

| 기능 | 먼저 만들 것 P0 | 이후 확장 P1 |
|---|---|---|
| 우측 상단 미니맵 | 내 위치·정원·발견 장소·걸어본 길, 접기/펼치기 | 미니맵 크기 조절 |
| `지도 보자` | 큰 지도 열기, 방향 선택, 정원 귀환 경로 표시 | 느리·모루·피오의 기록 레이어 |
| 길 발견 | 정원→모루 앞→분기→카페 야외, 실제 이동 후 발견 | 학교·직장·추가 연결 길 |
| 이야기 | 빈 이름칸→서로 다른 지도→홈 발견→선택, 중단·재개 | 장소별 후속 대화 |
| 내 자리 | 소유 의자 이동·취소·저장·앉기 | 지원 가구 회전·추가 장식 |
| 카페 | 외관·야외 벤치·기본 소리·같은 길 귀환 | 실내·창가·피오 대화 |
| 학교·직장 | 지도 데이터에 제안 구역으로만 보관 | 공부 준비/이어갈 일 남기기 장면 |

P0/P1은 제작 순서다. **빌드에 없는 장소를 미발견 장소로 속여 표시하지 않는다.** 어떤 장소도 미션·씨앗·구매 실적을 입장 조건으로 두지 않는다.

## 2. 지도 화면

### 작게 볼 때

- 우측 상단, 화면 안전 여백 안에 배치한다. 데스크톱 176×132px, 좁은 화면 128×96px는 **첫 시안 값**이며 실기기에서 조정한다.
- 북쪽 고정 지도에 현재 위치 화살표, 정원 집 모양, 발견 장소와 되돌아갈 길을 표시한다. 색 외에도 모양·선 종류로 구분한다.
- 버튼 이름은 `지도 보자`. 펼쳐진 지도에 키보드 포커스를 옮기고 닫으면 원래 버튼으로 돌려준다. 지도 단축키는 입력창·대화 선택 중 동작하지 않게 한다.
- 몰입을 위한 `화면 접기` 상태에서는 미니맵도 접는다. 작은 `지도`와 `화면 펼치기` 버튼은 남긴다. 자동 알림·반짝임·방문 독촉은 없다.

### 크게 볼 때

| 요소 | 표시/동작 |
|---|---|
| 제목 | `내가 걸어본 동네` |
| 구현·발견한 구역 | 장소명·방문 목적·최근 저장한 자리 확인 |
| 구현됐지만 미발견인 구역 | 현재 위치에서 이어지는 가까운 길의 짧은 끝만 표시. 전체 지형·장소명·실내·스토리 결말 숨김 |
| 아직 미구현인 구역 | 기본 지도에서 숨김. 사용자가 `앞으로의 동네`를 켜면 `준비 중` 범례로 별도 표시. 길찾기·목적지 선택 불가 |
| 목적지 | 발견된 구현 장소 또는 현재 확인 가능한 길 끝 중 하나 선택. `이쪽으로 가볼까요?`와 다음 분기 방향만 안내 |
| 귀환 | `정원으로 돌아가는 길`은 현재 구현·통행 가능한 길의 경로를 보여줌. 순간이동·자동걷기 없음 |
| 기록 | `이 자리 기억하기`로 발견한 장소를 책갈피. 자유 메모는 선택사항이며 자동 전송하지 않음 |
| 레이어 | 일반 지도는 항상 사용 가능. 세 주민 기록은 해당 대화를 본 뒤 사용자가 켜기. 여러 지도 중 정답을 고르는 기능 아님 |

초록 지붕 집의 **기존 외관**은 정원 랜드마크로 처음부터 표시한다. 신규 집 실내의 `enabled`·방문 발견은 외관과 별도다. 실내 미구현을 집 외관 미발견으로 표시하지 않는다. 세계 지도에는 입구만 표시하고 실내 방 구조는 겹쳐 그리지 않는다. 학교·직장은 가상 장소이며 이용자의 학적·고용·업무복귀 상태를 추정하거나 바꾸지 않는다.

## 3. 좌표와 동선 계약

`03_지도_스토리_데이터.json`은 **1000×700 정규화 설계 좌표**다. 실제 게임의 타일·충돌 좌표를 측정한 값이 아니다. 기존 정원의 큰 나무·초록 지붕 집·곡선길·중앙 잔디·입구 지도판은 유지하고, 실제 월드 좌표와 변환 어댑터를 연결한다.

| 노드 | 설계 좌표 | 연결 |
|---|---|---|
| 정원 `garden` | 180,480 | 집·모루 상점 |
| 집 `home` | 300,390 | 정원, 실내 입구 |
| 모루 상점 `shop` | 460,430 | 정원·분기 |
| 길의 분기 `junction` | 610,350 | 상점·카페·학교, 독립 장소 아님 |
| 카페 `cafe` | 760,450 | 분기 |
| 학교 `school` | 600,150 | 분기·직장 |
| 직장 `work` | 850,160 | 학교 |

모든 연결은 양방향이다. 아직 만들지 않은 학교·직장 연결은 경로 그래프에서 제외한다. P0의 귀환 경로는 `카페→분기→상점→정원`이다. 구역 전환 실패 때 마지막 안전 위치로 복귀하고 미션·인벤토리·배치를 보존한다. 장소 선택이 캐릭터 좌표를 바꾸면 안 된다.

## 4. ‘다음이 궁금한’ 단서 배치

한 번에 긴 할 일 목록을 보여주지 않는다. **현재 장면에서 확인한 사실 하나와 다음 질문 하나**만 제안하고, `나중에`를 항상 둔다.

| 단서 | 먼저 볼 수 있는 사실 | 궁금한 다음 행동 | 스포일러 방지 |
|---|---|---|---|
| 입구 지도판 | 이름칸이 비어 있음 | `지도판을 살펴볼까요?` | 뒤의 홈 아이콘·문구는 숨김 |
| 느리의 지도 | 빈 이름칸을 확인했고 느리의 지도는 아직 보지 않음 | `느리는 이 정원을 어떻게 그렸을까요?` | H06, 느리에게 안내 |
| 느리/모루 지도 | 같은 정원의 길 표시가 다름 | `모루는 왜 다르게 그렸을까요?` | 어느 지도가 정답인지 평가하지 않음 |
| 피오의 지도 | 모루의 지도까지 확인함 | `피오는 무엇을 지도에 남겼을까요?` | H07, 정원의 피오로 안내. 카페 방문 불필요 |
| 종이 귀퉁이 | 지도판 한쪽에 종이 모서리 | 직접 살펴볼 때만 보조 질문 표시 | H03은 자동 안내 슬롯 제외. NPC 대화 전에 지도판 복귀를 권하지 않음 |
| 머그 표지와 길 | 분기에서 머그 그림·카페 방향 | `저 길 끝에서 쉬어갈까요?` | 장소 도착 전 실내 구조·피오 대사 숨김 |
| 세 지도 확인 뒤 | 집·나무·입구 위치가 서로 같음 | `지도판에 다시 대어볼까요?` | 홈 발견 전 ‘숨겨진 홈 찾기’ 퀘스트 금지 |

길 단서는 다음 구역을 지나야만 본편이 열리는 조건이 아니다. 세 주민의 본편 지도 대화는 기존 정원에서도 만날 수 있게 유지한다. 카페·학교·직장은 본편 엔딩 조건이 아니다.

## 5. 이야기와 화면의 연결

- 본편 기준 ID는 `ST-P01 → ST-P02 → ST-A01 / ST-B01 / ST-C01 → ST-D01 → ST-E01`. 실제 선행 관계는 08의 개정 스토리와 확인 milestone에서 검사한다. 이 문서의 화살표는 대사 자동 재생 명령이 아니다.
- 08의 실제 확인 사실 `neuriMapSeen`·`moruMapSeen`·`pioMapSeen` 저장 성공 후 해당 기록 레이어를 선택 가능하게 한다. 기존 장면 완료 이력만으로 신규 확인 사실을 추정하지 않는다. 레이어를 켰다는 이유로 다음 대화를 완료 처리하지 않는다.
- 본편 단서 흐름은 `P02→H06/A01→H02/B01→H07/C01→H05/D01`이다. 활성 질문은 한 개이며 카페 길 H04는 사용자가 길 탐색을 고를 때 대신 제안한다. `ST-D01`은 08의 선행 확인 사실과 사용자의 지도판 상호작용으로 연다. 지도 UI에서 모든 레이어를 켜거나 구매·꾸미기를 끝내야 한다는 조건을 추가하지 않는다.
- 이름·표시·세 지도 함께 두기·보류는 08의 `r2-D01-*` 화면동작과 `storyDecision`에 매핑한다. 구 선택 ID와 r2 선택을 동시에 실행하지 않는다. 이름 패널을 닫는 `pending`은 새 엔딩 결정을 만들지 않는다. 지도판 홈은 `ST-D01`의 발견 대사를 실제 확인한 뒤 표시한다. 장면 진입만으로 선공개하지 않는다.
- 대화 닫기와 마지막으로 확인한 대사, 선택 저장·완료를 구분한다. 새로운 지도 UI를 여는 행동은 기존 대화를 강제 종료하거나 완료시키지 않는다.
- 신규 장소 첫 안내와 기존 튜토리얼을 동시에 재생하지 않는다. `ST-V01/V02/V03`, `ST-X01`과 튜토리얼 중 한쪽을 안내 소유자로 정한다. 장소 발견만으로 대화를 완료하지 않는다.

## 6. 상태·저장·오류 처리

| 상태 | 저장 내용 | 금지할 혼동 |
|---|---|---|
| 제작 여부 | 빌드 매니페스트의 `featureEnabled` | 방문 여부와 동일 필드로 처리하지 않기 |
| 발견 | 구현 구역에 캐릭터가 실제 진입한 이력 | 지도에서 누르기·바로가기 상점 열기와 구분 |
| 이야기 | 확인 대사 커서·선택·완료 장면 | 장소 도착이나 패널 열기로 자동 완료 금지 |
| 지도 | 확인한 길·노출 단서·기록 레이어·목적지·책갈피 | 미발견 장소·스토리 반전의 사전 노출 금지 |
| 배치 | 소유 가구의 저장 배치와 편집 초안 | 상품 미리보기·목표 저장과 구분 |

이번 데이터는 개발 환경에서 쓸 저장 어댑터를 정의한다. 운영 저장소는 기존 `saveAuthority` 결정 후 연결한다. 브라우저 로컬 저장을 택하면 버전이 있는 한 레코드로 저장하고, 새 상태 저장에 실패하면 마지막 정상 레코드를 유지한다. 저장 실패 상태에는 `이 자리 기억하기` 성공·장면 완료 표시를 하지 않는다.

발견 표시가 먼저 화면에 필요하면 `저장 중` 임시 상태로 보여줄 수 있지만, 저장 완료 전 영구 발견이라고 말하지 않는다. `zone_enter`의 중복 호출은 동일 구역 발견을 한 번만 기록한다. 구버전에는 기존에 실제 방문했다고 확인 가능한 구역만 이관하고 전체 공개하지 않는다. 새 필드가 생겨도 씨앗·열매·미션·배치 레코드를 초기화하지 않는다.

목적지가 미구현으로 바뀌거나 경로가 끊기면 목적지를 해제하고 `지금은 이 길로 갈 수 없어요`를 표시한다. 플레이어 위치가 유효하지 않으면 마지막 안전 위치로 이동한다. 경로 탐색 실패를 지도 스토리나 경제 진행의 실패로 기록하지 않는다.

### 학교·직장 개인 메모

08의 `r2-V02-C1-A1`은 학교 준비 메모, `r2-V03-C1-A1`은 직장 이어갈 일 메모를 사용자가 직접 입력·저장하는 하위 선택이다. `*-A2` 자리만 보기나 패널 닫기는 새 메모를 만들지 않고 기존 메모도 삭제하지 않는다.

저장 키는 이용 저장본·장소·메모 종류 조합으로 한 건을 수정한다. 본문·revision·저장시각을 저장하고, 편집 초안과 마지막 확정 메모를 분리한다. 저장 실패는 초안·이전값을 보존하고 성공 대사를 숨긴다. NPC 대본용 관찰·시안 메모, 개인 메모, 장소 책갈피는 서로 다른 상태다. 메모 작성이 책갈피·본편 사실·실제 수행·학적·업무복귀·씨앗을 만들지 않는다. 자유 입력 원문은 계측에 전송하지 않으며 입력 제한·운영 저장 위치는 기존 어댑터 결정 후 적용한다.

## 7. 입력과 접근성

- 기존 이동 조작을 재사용한다. 구체 키는 현재 코드 확인 전 하드코딩하지 않는다. 지도 열기 `M`은 제안이며 입력창·한글 조합·대화 중에는 가로채지 않는다.
- 지도 위 클릭/터치는 목적지 선택만 한다. 키보드 사용자는 장소 목록과 방향 버튼으로 같은 기능을 쓸 수 있다. `Escape`·닫기 버튼 모두 원래 포커스로 복귀한다.
- 작은 지도 안의 작은 아이콘을 필수 터치 대상으로 삼지 않는다. 큰 지도 열기 버튼과 장소 목록의 터치 영역은 최소 44 CSS px를 시안 기준으로 잡고 기기 검수한다.
- 소리 없는 환경에서도 머그·책·작업등 그림과 방향 문장으로 길을 찾을 수 있다. 반짝임·이동 화살표는 줄일 수 있고, 색상만으로 발견·미발견을 구분하지 않는다.
- 스크린리더 안내는 `현재 정원. 동쪽 길은 모루 상점 방향.` 같은 문장으로 제공한다. 좌표 변화 매 프레임 낭독하지 않고 구역·분기가 달라질 때만 갱신한다.

## 8. 개발 작업과 완료 기준

| 작업 | 완료 기준 |
|---|---|
| MAP-01 기존 월드 연결 | 제안 노드와 실제 입구·충돌·전환 영역 매핑. 각 구현 구역에 정원으로 돌아오는 통행 가능 경로 존재 |
| MAP-02 지도 UI | 우측 상단 표시·접기·큰 지도·닫기·포커스 복귀. 화면 회전/좁은 화면에서 버튼 가림 없음 |
| MAP-03 발견·경로 | 실제 걷기 후 발견, 지도 클릭 발견 없음. 미구현 구역은 경로 탐색에서 제외 |
| MAP-04 단서·기록 | 선행 대사를 본 힌트만 노출. 홈·엔딩 선택 선공개 없음. 레이어 없이 본편 완결 |
| MAP-05 저장·복원 | 중복 발견 한 번 기록, 저장 실패 보존, 목적지 무효화·구버전 이관 검수 |
| MAP-06 기존 기능 회귀 | 미션 수행0회·구매0회 본편 완결. 상점 바로가기는 제자리. 가구 저장·착석·패널 복원 |

**필수 검수 경로:** ① 무음으로 정원→카페→정원 ② 지도만 눌러 발견되지 않음 ③ 미구현 학교에 목적지 설정 불가 ④ 지도판 홈 이전 모든 지도 패널 스포일러 검사 ⑤ 대화 도중 종료·저장실패·재접속 ⑥ 미션0회·구매0회·레이어 미사용으로 엔딩 ⑦ 학교 방문해도 학업/고용/업무복귀 상태 불변 ⑧ 작은 화면·키보드만 사용·움직임 줄이기 ⑨ 상점 미리보기 뒤 위치·실배치 불변.

기능 공수·현재 엔진의 지원 여부·운영 저장소·실측 지도 좌표는 코드를 본 뒤 확정한다. 아래 JSON의 좌표·UI 크기·지도 키는 구현 가정이며 성능이나 사용자 효과 검증값이 아니다.

## 9. 지도 첫 안내와 연속성 반응

기존 튜토리얼 12개는 유지하고 지도 첫 안내 두 개를 추가한다. MAP-T01은 “오른쪽 위 지도를 누르면 걸어온 길이 보여요.”, MAP-T02는 첫 목적지 표시 후 “갈 곳만 표시했어요. 표지를 따라 직접 걸어가볼까요?”다. 기존 첫 안내·장소 대사와 동시에 띄우지 않고 건너뛰기·도움말 재확인을 제공한다.

ST-S01의 네 번째 돌 발견과 ST-S06의 조용한 자리 대사는 실제 확인 커서 저장을 기준으로 기억한다. 서브 장면을 중간에 닫아도 이미 확인한 사실을 보존한다. E01·C01 응답은 확인/미확인/이관 불명 상태로 나누고, V03은 실제 정원 표식 저장을 확인한 경우에만 사용자 선택을 언급한다. 조건과 중립 대사는 `08`이 권위다.
