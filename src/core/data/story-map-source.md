# 틈새정원 최종 스토리

2026-11-15 사용자 지도 표현 변경: 느리는 큰 나무·돌담·돌, 모루는 길, 피오는 아직 발견하지 않은 곳의 안개를 기록한다. 아래 원고의 지도 소개 대사를 이에 맞춰 조정했다. 피오의 소리 수집가 설정과 별도 소리 이야기는 유지한다. 이전 소리 지도·집 아이콘 관련 연출 설명보다 이번 지도 표현 변경을 우선하며, 장면 ID·조건·보상은 변경하지 않는다.

이 문서에 본편 14·주민 서브 6·복귀 10·공간 확장 4, 총 34장면의 원고를 모두 담았다. 개정 데이터는 `08_스토리_개정데이터.json`, 지도·구현 계약은 `02_개발자_구현안.md`와 `03_지도_스토리_데이터.json`을 함께 본다. 아래 대사와 구현 지시는 구분하며, 작성 완료가 게임 적용 완료를 뜻하지 않는다.

## 이야기 요약

이름 없는 정원에 새싹이가 찾아온다. 느리는 돌과 그늘을 보는 지도, 모루는 길 찾기 쉬운 지도, 피오는 소리 지도를 가지고 있다. 세 지도는 같은 정원을 다르게 기록한 것이다. 새싹이는 지도판 덮개 아래의 홈을 발견하고, 자기 지도를 더하거나 세 지도를 함께 두거나 이름을 비워둘 수 있다.

## 게임이 전하는 말

> 작은 일을 해낸 날도, 잠시 쉬어가는 날도, 당신이 돌아올 자리를 가꿉니다.

현실의 작은 행동은 씨앗과 정원 가꾸기로 이어진다. 이야기에서는 길을 걷고 주민들의 표시를 비교하며, 내 공간을 어떻게 남길지 선택한다. 직접 꾸민 자리에 앉아 켜둘 수도 있다. 이 세 경험은 함께 이용할 수 있지만 어느 하나를 끝내야 다른 것을 쓸 수 있는 구조는 아니다.

## 이야기의 동력

새싹이에게 정해진 과거는 없다. 정원에 들어온 이유도 플레이어 대신 설명하지 않는다. 첫 목표는 **‘빈칸에 뭘 적을지 정하기 전에, 여기가 어떤 곳인지 알아보기’**다.

주민 셋은 서로 다른 목적의 지도를 가지고 있어 한 장만 걸면 다른 표시가 빠진다고 생각해 왔다. 누가 잘못 그렸는지 다투는 큰 갈등은 없다. 같은 나무·집·입구가 맞는데도 서로 다른 지도처럼 보인다는 작은 불일치가 질문을 만든다. 마지막에는 여러 장을 갈아 끼울 수 있었던 구조를 발견한다. 정답 지도를 골라야 했던 문제 자체가 달라진다.

| 인물 | 처음의 행동 | 플레이 중 드러나는 변화 | 마지막에 남는 행동 |
|---|---|---|---|
| 느리·달팽이 | 좋아하는 돌을 볼 수 있는 우회로부터 권함 | 새싹이가 집으로 먼저 가거나 지도만 봐도 자기 추천을 강요하지 않음 | 자기 지도에 ‘돌을 보고 싶을 때’라는 목적을 붙임 |
| 모루·두더지 | 가장 알아보기 쉬운 표시 하나를 고르려 함 | 두 표시를 함께 두거나 고치겠다는 선택을 받아들임 | 지우개 달린 연필과 바꿔 끼우는 표지를 둠 |
| 피오·참새 | 처음 듣는 소리만 수첩에 적음 | 조용한 자리·다시 듣는 소리도 지도에 남김 | 소리 없음·다시 듣기 표시를 함께 씀 |
| 새싹이·플레이어 | 빈 이름칸과 서로 다른 지도를 관찰 | 따라가기·비교·수정·보류 중 직접 선택 | 자기 지도, 함께 보는 지도, 빈칸 중 현재 선택을 남김 |

주민은 플레이어에게 고쳐져야 하는 사람이 아니다. 사용자가 참여를 보류해도 주민의 생활은 이어지고 관계에 벌점이 없다. 각 변화는 대화와 작은 물건의 사용 방식으로 표현한다.

프롤로그·4장·에필로그의 기존 이야기 구간은 유지한다. 아래 7개는 장 번호가 아니라 인과상 필요한 사건이며 현실 미션의 6단계 추천과 별개다.

## 원고와 저장 데이터 사용

이 개정에서 본편 10장면과 공간 4장면의 원고·선택을 바꾸고 나머지 20장면은 기존 원고를 유지했다. 각 장면 머리에 구분을 표시한다. 장면 ID는 같지만 바뀐 선택은 `r2-` 접두사를 쓴다. 기존 20장면은 원래 선택 ID를 그대로 쓴다. 이전 저장의 장면 확인 사실과 소유품·기록·경제 결과는 유지하고, 새 선택 결과를 과거 선택에서 추정 생성하지 않는다. 같은 장면의 구버전·개정 선택을 동시에 실행하지 않는다.

개정 장면의 선택 표시와 저장은 `08_스토리_개정데이터.json`의 개정 버전을 사용한다. 원래 완료 사실은 별도 확인 이정표로 이관하고, 아직 보지 않은 개정 선택은 재대화로 열 수 있다. 재접속 후 이미 확인한 단서·본편 진행을 다시 강제하지 않는다.

| r2-B03-C4 | 나중에 구경할게요 | 상점 닫기. 이야기 계속 가능 |

**연출·저장:** 미소유 상품 미리보기에는 ‘구매 전’ 표시. 구매 성공 후에는 “네 물건은 보관함에 넣었어.”, 배치 저장 성공 후에는 “이번엔 그 자리에 놓았구나.”, 실제 의자에 앉은 뒤에만 “창 쪽이 잘 보이네.”처럼 위치에 맞는 반응을 쓴다. 지도 단서를 상품에 넣거나 일반 가구를 대화 보상으로 지급하지 않는다.

**다음 궁금증:** 같은 방도 자리를 바꾸면 다르게 보일까? 집꾸미기는 별도 선택 흐름이며 본편 조건이 아니다.

### ST-C01 · 아직 펼쳐보지 않은 곳의 안개

원고·선택 개정 · 선택 ID `r2-` 사용


**사건·목적:** 집 앞 선반에서 피오의 지도를 본다. 세 지도의 나무·집·입구 위치가 일치함을 직접 비교한다. 소리는 필수 청각 퍼즐로 만들지 않는다.

**대사**

- 피오: “내 지도엔 아직 걸어보지 않은 곳의 안개만 남겼어.”
- 피오: “길을 따라 새로운 곳을 만나면 그 자리의 안개가 걷혀.”
- 피오: “느리의 나무랑 돌담, 모루의 길도 같은 자리에 있네.”
- 피오: “종이를 겹치면 표시만 다르겠다. 그런데 판에는 한 장만 걸리는 걸까?”

**선택**

| ID | 버튼 | 대사·결과 |
|---|---|---|
| r2-C01-C1 | 안개가 있는 곳은 못 지나가나요? | 피오: “아니, 안개는 아직 가보지 않았다는 뜻이야. 이어진 길을 따라가며 둘러볼 수 있어.” 실제 연출·이야기에서 확인한 소리만 표시 |
| r2-C01-C2 | 조용한 자리 이야기도 듣고 싶어요 | 피오의 응답은 ST-S06 실제 확인·표시 상태에 따라 아래 조건부 대사를 사용. 이번 선택으로 조용한 자리 기호를 저장 |
| r2-C01-C3 | 소리 이야기는 다음에 들을게요 | 피오: “좋아. 소리 수첩은 따로 챙겨둘게.” 다시 듣기 기호 |
| r2-C01-C4 | 지도 모양만 볼게요 | 피오: “안개가 걷힌 자리와 다른 지도의 위치를 비교해봐.” 음소거 상태에서도 같은 비교 정보 제공 |

**조용한 자리 응답 조건:** ST-S06의 조용한 자리 대사를 이미 확인한 경우, 당시 쉼표·무음·빈칸 중 무엇을 골랐든 피오: “그늘에서 조용한 자리도 봤지. 이번엔 이 기호로 남겨두자.” 미확인인 경우에는 피오: “아무 소리도 안 적힌 게 빈칸은 아니었네.”라고 말한다. 예전 기호가 존재했다고 단정하지 않고 이번 선택으로 기호를 남긴다. 확인 여부는 실제 대사 확인 기록을 사용한다. 이전 기록이 불명확하면 피오: “조용한 자리도 이 기호로 남겨두자.”라는 중립 응답을 사용한다.

**연출·저장:** 세 지도는 대화용 비교 화면에 함께 나타난다. 세 실물 아이템을 가방에 모으는 수집 조건이 아니다. 피오의 지도 확인 뒤 수첩에 **‘입구 지도판을 다시 살펴볼까?’**가 생긴다. 자동 귀환·워프 없음.

### ST-C02 · 같은 자리의 다른 소리 — 선택 심화

원고·선택 개정 · 선택 ID `r2-` 사용

**대사**

- 피오: “아까 그 자리에 다시 갔어. 새 소리는 못 찾았는데, 전에 못 적은 소리가 있더라.”

### ST-D01 · 지도판의 홈

원고·선택 개정 · 선택 ID `r2-` 사용


**사건·목적:** `ST-P02·ST-A01·ST-B01·ST-C01`을 본 뒤 플레이어가 지도판을 다시 살펴본다. 처음의 종이 귀퉁이를 짚고 덮개를 확인한다. 집 앞 선반의 공용 나무 받침을 빌려 덮개를 받치는 짧은 연출 후 바로 반납한다. 구매·소유품·현실 정리 행동과 관계없다.

**대사**

- 모루: “종이가 걸린 게 아니네. 이 안쪽으로 들어가 있어.”
- 연출: 덮개 아래에서 얇은 홈이 드러난다. 비교하던 세 종이를 차례로 넣었다 빼는 모습. 실제 나무·집·입구 위치가 일치한다.
- 느리: “한 장을 고르는 판인 줄 알았는데, 바꿔서 걸 수 있었구나.”
- 피오: “아직 가보지 않은 곳이 궁금할 땐 내 거, 나무랑 돌을 볼 땐 느리 거!”
- 모루: “길을 볼 땐 내 걸 쓰고. 새로 그린 종이도 들어가겠네.”
- 모루: “네가 남길 건 어떻게 할래?”

**선택**

| ID | 버튼 | 결과·대사 |
|---|---|---|
| r2-D01-C1 | 내 지도를 만들어볼게요 | 이름·표식 작성 또는 빈칸 유지. 임시 이름이 있으면 가져올지 확인. 모루: “연필은 옆에 둘게. 나중에 고쳐도 돼.” |
| r2-D01-C2 | 세 지도를 함께 볼래요 | 지도판에서 세 관찰 지도 전환. 피오: “오늘 보고 싶은 걸 펼치면 되겠다.” |
| r2-D01-C3 | 이름은 비워둘게요 | 이름칸 유지, 홈 발견과 본편 선택 완료. 느리: “그럼 다음에 봐도 이 칸은 찾기 쉽겠다.” |

**연출·저장:** 반전 확인과 현재 선택을 각각 저장한다. 이름 작성 창을 그냥 닫으면 작성 보류이며, 명시적으로 ‘지금은 비워두기’를 고르면 엔딩으로 이어진다. 어떤 선택에도 우열·성취 등급을 붙이지 않는다. 주민 누구도 이 구조를 원래 알고 있었다고 말하지 않는다.

**다음 궁금증:** 내가 남긴 선택으로 정원은 어떻게 보일까?

**이름 작성 하위 선택:** `r2-D01-NAME-SAVE`는 입력한 이름을 저장하고, `r2-D01-NAME-EMPTY`는 명시적으로 이름을 비워둔 채 에필로그로 이어진다. `r2-D01-NAME-CANCEL`은 작성 창만 닫고 현재 본편 선택을 보류한다. 저장·빈칸 선택·단순 닫기를 같은 완료로 처리하지 않는다.


### ST-E01 · 다음에 펼칠 지도

원고·선택 개정 · 선택 ID `r2-` 사용


**사건·목적:** 집 앞에서 지금의 지도판을 바라본다. 실제 고른 지도·이름·빈칸을 화면에 보여준다. 주민의 변화는 설명 대신 한 번의 행동으로 마무리한다.

**대사·연출**

- 느리가 자기 지도에 작은 글씨를 쓴다. “이건 ‘돌 보고 싶은 날’이라고 적어야겠어.”
- 모루가 연필을 지도판 옆에 둔다. “다음 표시는 써보고 고치자.”
- 피오는 실제 ST-C01 선택에 맞는 표시를 수첩에 남긴다. 조용한 자리 선택이면 “조용한 자리도 찾기 쉽게 해뒀어.”, 다시 듣기 선택이면 “다시 듣고 싶은 곳은 이 표시야.”, 다른 소리 선택이면 “소리마다 자리를 적어뒀어.”라고 말한다. 지도만 본 경우에는 표시를 새로 만들었다고 하지 않고 “다음에 적을 자리도 남겨뒀어.”라고 말한다.
- 돌 대사는 아래의 실제 발견 상태에 맞는 한 묶음만 재생한다.
  - ST-S01에서 ‘하나 더 있네’ 발견 대사를 아직 보지 않은 것이 확인됨: 느리 “난 저 돌 셋을 다시 보고 올게. 네 번째가 있는지도 보고.” → 피오 “이번엔 찾으면 알려줘.” → 느리 “이름부터 떠오르면 어쩌지?”
  - ST-S01의 해당 발견 대사를 실제로 확인함: 느리 “새로 찾은 돌도 다시 보고 올게.” → 피오 “이번엔 어디가 달라 보이는지 적어둬.”
  - 이전 확인 상태가 불명확함: 느리 “난 그늘에 있는 돌을 다시 보고 올게.” → 피오 “이번엔 어디가 달라 보이는지 적어둬.”
- ST-S01의 선택이나 장면 완료만이 아니라 발견 대사의 실제 확인 지점을 기준으로 한다. 발견 대사 뒤 창을 닫은 경우도 이미 발견한 상태다. 실제 하루 경과나 지난 방문 시각을 추정하는 ‘어제도’ 표현은 쓰지 않는다.

**선택:** `r2-E01-C1` 조금 더 꾸밀게요 / `r2-E01-C2` 지금 모습이 좋아요 / `r2-E01-C3` 나중에 다시 올게요. 각각 자유 꾸미기, 현재 상태로 머무르기, 자유 화면·종료로 연결한다. 미접속 손실이나 주민의 서운함은 없다.

**후속 한 줄은 실제 상태에 맞춰 하나만:** 미개봉 씨앗 보유 → 씨앗함 안내 / 수확 가능 식물 → 수확 선택 안내 / 그 외 → “오늘은 어느 길부터 둘러볼래?” 상태가 확인되지 않으면 일반 탐색 대사만 사용한다.

**확장 훅:** 이용 가능한 미발견 길이 있으면 미니맵 가장자리에 그 길의 짧은 조각만 남는다. 이미 다 발견했으면 ‘방문하지 않은 곳이 있다’고 말하지 않고 실제 저장한 자리·현재 배치·주민 서브 중 선택한다. 엔딩은 정원 사용의 종료가 아니다.

- 제작 범위: P1 주민 에피소드

### ST-V01 · 카페 앞 — 길을 보는 벤치

원고·선택 개정 · 선택 ID `r2-` 사용


**발견 전 단서:** 실제 카페 연결 길 초입에서 머그 그림 표지가 보인다. 소리 없이도 방향이 보이며, 문장 안내는 “머그 그림 표지 너머엔 어떤 자리가 있을까?”다. 목적지 건물·내부를 미리 다 보여주지 않는다.

**작은 사건:** 피오의 메모에는 카페가 ‘잎 소리’로만 적혀 있다. 그러나 벤치에서는 정원 나무보다 걸어온 길과 잎 그림 귀환 표지가 먼저 보인다. 피오는 처음 적은 이름이 그 자리의 전부는 아니라는 것을 발견한다.

- 피오: “이 벤치에선 네가 걸어온 길이 보여.”
- 피오: “난 ‘잎 소리’라고만 적었는데, 여기선 길을 보는 것도 좋겠다.”
- 피오: “너는 뭘 먼저 볼래? 돌아갈 땐 저 잎 그림 표지야.”

| 개정 선택 ID | 선택·사건 결과 | 화면에 남는 변화 |
|---|---|---|
| r2-V01-C1 | 자리 살펴보기 → 벤치 옆에서 길과 정원을 바라봄 | 피오가 ‘길이 보이는 벤치’라는 관찰 메모를 덧붙임. 사용자 책갈피는 별도 선택 |
| r2-V01-C2 | 더 둘러보기 → 건물 외관·머그 표지를 살펴봄 | 피오: “머그 그림을 그려두면 다시 찾겠네.” 카페가 발견 지도에 기록됨 |
| r2-V01-C3 | 돌아가는 길 보기 → 귀환 표지 확인 | 피오: “벤치 말고 표지부터 적을게.” 귀환 안내를 표시하고 자유 이동 |

세 선택은 모두 자유 이동으로 합류한다. 카페 발견 자체는 실제 구역 진입으로 기록하고 선택별 관찰 메모만 다르게 남긴다. 앉기는 별도 입력이다. 실내가 준비되지 않았다면 문을 열 수 있다고 말하거나 실내 스토리를 자동 예고하지 않는다.

**다음 단서:** 실내가 열려 있고 문을 직접 확인했다면 ‘창문 안에서는 같은 길이 어떻게 보일까?’를 선택 질문으로 제안한다. 아직 실내가 없으면 실제 길의 분기나 귀환 방향만 보여준다.

### ST-V02 · 학교 — 첫 장을 찾는 책상

원고·선택 개정 · 선택 ID `r2-` 사용


**발견 전 단서:** 실제 학교 연결 길의 책 그림 표지와 창문 너머 책장 일부. 문장 안내는 “책 그림 표지 끝에는 어떤 책상이 있을까?”다.

**작은 사건:** 피오가 자기 메모에서 ‘종이’라고 쓴 두 칸을 발견한다. 하나는 책장 앞, 하나는 책상 앞에서 적었는데 위치를 빼먹었다. 새싹이는 어느 쪽부터 볼지 고른다. 잘못된 답을 맞히는 퍼즐이 아니라, 메모가 다음 방문에 쓸모 있으려면 무엇이 필요한지 직접 보는 사건이다.

- 피오: “두 군데 다 ‘종이’라고 적었더니 어디였는지 헷갈려.”
- 피오: “하나는 저 책장 앞이었어. 다른 하나는 책상이고.”
- 피오: “어느 쪽부터 표시해둘까?”
- 메모 저장 성공 뒤 화면: “준비할 일을 남겼어요.”

| 개정 선택 ID | 선택·대사 | 변화 |
|---|---|---|
| r2-V02-C1 | 책상 자리 살펴보기. 피오: “여긴 펼쳐놓고 보는 자리라고 적어야겠다.” | 책상 그림 관찰 메모. 뒤 패널에서 준비할 일 하나를 남기거나 자리만 보기 |
| r2-V02-C2 | 책장 쪽 둘러보기. 피오: “여긴 뭘 볼지 고르는 자리네.” | 책장 그림 관찰 메모. 사용자가 책상을 아직 고르지 않았다고 그대로 유지 |
| r2-V02-C3 | 길 안내 보기. 피오: “그럼 돌아가는 표지부터 적자.” | 출구·귀환 방향 표시. 준비 메모 없이도 장면 종료 |

`r2-V02-C1` 뒤 선택 패널에 **‘준비할 일 남기기 / 자리만 보기’**를 추가한다. 전자를 고르면 먼저 펼칠 자료나 준비할 일 하나를 플레이어가 직접 적는다. 학적 상태나 과제 존재를 미리 단정하지 않는다. 새 본편 장면이나 현실 미션 완료가 아니다. 실제 공부 행동은 사용자가 따로 활동 메뉴를 열 때 선택한다.

**다음 단서·다시 오는 이유:** 실제 메모를 남긴 경우 “어디서 시작할지 다음에도 찾을 수 있겠네.”라고 반응한다. 비워두면 피오가 자기 메모에 위치만 더한다. 직장 길의 책상 표지를 이미 본 경우 ‘다른 작업 자리에는 뭘 남겨둘까?’를 선택 질문으로 볼 수 있다. 학교가 직장을 여는 조건은 아니다. 직접 남긴 메모와 자리를 다시 열 수 있지만 새 메모·공부 시간을 요구하지 않는다.

**준비 메모 하위 선택:** `r2-V02-C1-A1` 준비할 일 남기기 / `r2-V02-C1-A2` 자리만 보기. A1을 골라도 실제 메모 저장을 취소하면 기존 메모를 유지한다. A2는 기존 메모를 삭제하는 명령이 아니다.


### ST-V03 · 직장 — 이어갈 일을 남기는 자리

원고·선택 개정 · 선택 ID `r2-` 사용


**발견 전 단서:** 실제 직장 연결 길의 작은 책상 그림 표지와 작업등이 보이는 창. 문장 안내는 “책상 그림 표지가 가리키는 곳은 어떤 자리일까?”다.

**작은 사건:** 모루가 작업대에서 다음에 손볼 두 표지 시안을 찾는다. 한 장은 잎 그림이 작고, 다른 한 장은 화살표가 가늘다. ‘고치기’라고만 적어두니 어느 부분이었는지 다시 살펴봐야 했다. 새싹이는 어느 시안을 먼저 볼지 고를 수 있다. 장면 안 시안의 메모만 바뀌며 정원 길·기존 표식 선택은 바뀌지 않는다.

- 모루: “‘표지 고치기’라고 적었는데, 뭘 고칠지 안 적었네.”
- 모루: “하나는 잎이 작고, 하나는 화살표가 가늘어. 어느 것부터 볼까?”
- 모루: “네가 이어갈 것도 있으면 한 줄 남겨도 돼.”
- 메모 저장 성공 뒤 화면: “다음에 할 일을 남겼어요.”

| 개정 선택 ID | 선택·사건 결과 | 변화 |
|---|---|---|
| r2-V03-C1 | 작업 자리 살펴보기. 잎 시안을 보고 모루가 ‘잎 그림 크게 하기’라고 적음 | 모루의 작업 메모 그림 변경. 뒤 패널에서 이어갈 일 남기기 또는 자리만 보기 |
| r2-V03-C2 | 물건 둘러보기. 화살표 시안을 보고 모루가 ‘화살표 굵게 하기’라고 적음 | 다른 시안 메모 그림. 구매·지급·플레이어 소유권 변경 없음 |
| r2-V03-C3 | 길 안내 보기. 시안은 모루에게 맡기고 출구 확인 | 실제 귀환 방향. 본편·메모 작성과 관계없이 자유 이동 |

`r2-V03-C1` 뒤 **‘이어갈 일 남기기 / 자리만 보기’**를 추가한다. 플레이어 메모와 모루의 대본용 시안 메모는 별도다. 고용·복귀 상태를 자동 생성하지 않는다. 외부 문서·회사명·업무 내용을 자동으로 가져오지 않는다. 상점 밖 구매 기능은 넣지 않는다.

**변화·다음 단서:** 모루: “다음엔 이 줄부터 보면 되겠다.” 사용자 메모가 없어도 모루의 작은 사건은 끝난다. 모루는 시안을 작업대에 둔다. ST-B01에서 집 방향·그늘·둘 다 중 현재 표식이 실제 선택·저장된 경우에만 “정원 표시는 네가 고른 대로 있어. 돌아가서 볼래?”라고 말한다. ST-B01 미확인·표식 보류·저장 불명확이면 “정원으로 돌아가는 표지는 입구에 있어. 돌아가서 볼래?”라고 말한다. 실제 미발견 길이 있으면 그 방향을 선택할 수도 있다. 남긴 문장과 작업 자리를 다시 볼 수 있지만 완료 체크·처리량을 요구하지 않는다.

**다음 행동 메모 하위 선택:** `r2-V03-C1-A1` 이어갈 일 남기기 / `r2-V03-C1-A2` 자리만 보기. 메모 저장 성공 전에는 완료 대사를 띄우지 않는다. A2는 기존 메모를 유지하고 장소를 감상한다.


### ST-X01 · 카페 창가 — 바깥길을 다른 쪽에서

원고·선택 개정 · 선택 ID `r2-` 사용


**조건:** 실제 카페 실내와 창가가 구현된 뒤만 사용. 음원 미구현이면 소리는 피오가 수첩에 적어둔 관찰로 표현한다.

- 피오: “밖에서는 잎을 적었는데, 이쪽엔 찻잔을 적었어.”
- 피오: “같은 길인데 창문을 사이에 두니까 다르게 보인다.”
- 피오: “그런데 문 쪽은 또 다르네. 발소리라고 적어야 하나?”
- 피오: “어느 쪽부터 볼래?”

| 개정 선택 ID | 선택 | 결과·조건 |
|---|---|---|
| r2-X01-C1 | 창가 자리 보기 | 바깥길 그림과 찻잔 표시를 관찰 메모로 남김. 앉기는 별도 선택 |
| r2-X01-C2 | 문가 둘러보기 | 문과 발자국 표시를 관찰 메모로 남김. 창가 기록을 자동으로 만들지 않음 |
| r2-X01-C3 | 그냥 지나가기 | 메모 없이 자유 이동. 미확인 대화는 나중에 다시 접근 가능 |
| r2-X01-C4 | 이 자리 책갈피 | 실제 방문한 자리 중 고른 자리가 존재할 때만 노출. 저장 성공 뒤 피오: “수첩에 이 자리를 끼워뒀어.” |
| r2-X01-C5 | 소리만 들어볼게요 | 대화창 접기·머무르기. 음소거 상태에서도 장소 이용 가능. 현실 수행·보상 자동 기록 없음 |
| r2-X01-C6 | 이제 일어날게요 | 실제 착석 상태일 때만 노출. 일어나기 후 자유 이동. 서 있을 때는 일반 나가기 제공 |

같은 카페 안에서도 선택에 따라 보이는 조각이 달라진다. 관찰 메모와 사용자의 장소 책갈피는 별도이며, 실제 저장 전에는 완료 대사를 띄우지 않는다.

**변화·다음 단서:** 피오가 수첩의 한 줄을 지우지 않고 ‘밖·창가·문가’ 세 칸으로 나눈다. “카페 하나에 이름이 세 개네. 다른 종이 소리도 구분해서 적어볼까?” 이후 학교 방향을 실제로 확인한 경우에만 책 그림 표지 질문을 별도로 고를 수 있다. 학교 방문·전체 칸 수집을 요구하지 않는다. 카페 운영·주문·매출 시스템은 추가하지 않는다.

## 지도와 다음 질문의 표현


우측 상단 미니맵에는 **현재 위치·실제로 발견한 길·정원 귀환 방향**을 먼저 보여준다. 버튼 문구는 **‘지도 보자’**다. 펼치면 발견한 장소, 주민의 지도 메모, 사용자가 고른 다음 질문 하나를 확인한다. 닫기·접기와 키보드 접근을 제공하며 머무르기 중에는 작게 접을 수 있다.

지리 지도는 실제 위치를 안내한다. 느리·모루·피오의 그림은 같은 지형 위에 겹치는 **관찰 메모**다. 본편에서 세 지도를 보기 전에는 주민별 전체 그림을 먼저 펼쳐 반전을 설명하지 않는다. 홈 발견 전에도 일반 지도는 정상 이용할 수 있으며, 홈 발견은 관찰 지도 전환 연출의 의미를 설명하는 사건이다.

| 지도 단서 ID | 관찰·노출 조건 | 질문의 방향 |
|---|---|---|
| H01_BOARD_NAME | 시작 지도판이 보이고 ST-P02 미확인 | 이름칸이 왜 비었을까? |
| H02_MORU_ROUTE | ST-A01 지도 확인, ST-B01 미확인 | 모루의 길 표시는 왜 다를까? |
| H03_PAPER_CORNER | ST-P02에서 종이 귀퉁이를 실제 확인 | 저 종이는 어떻게 들어가 있을까? 홈이라는 답을 표시하지 않음 |
| H04_CAFE_PATH | 구현된 카페 길 입구의 머그 표지를 실제 확인 | 머그 그림 표지 너머엔 어떤 자리가 있을까? |
| H05_COMPARE_MAPS | ST-A01/B01/C01 지도 확인, ST-D01 발견 미확인 | 같은 곳을 그린 종이를 지도판에서 다시 볼까? |
| H06_NEURI_MAP | ST-P02 확인, ST-A01 미확인 | 느리가 그늘에 둔 지도에는 뭘 그렸을까? |
| H07_PIO_MAP | ST-B01 확인, ST-C01 미확인 | 피오의 지도에는 길 말고 뭘 적었을까? |

`layer_neuri`·`layer_moru`·`layer_pio`는 각각 ST-A01·ST-B01·ST-C01의 지도 확인 뒤 수동 선택한다. 홈 발견 기록 `confirmedMilestones.mapBoardGrooveSeen`은 ST-D01의 발견 대사를 실제 확인한 뒤만 참이다. 장면에 들어왔다는 이유만으로 홈·결말을 보여주지 않는다. 활성 질문은 위 단서와 장소 관찰 질문을 통틀어 한 개이며, 사용자가 바꾸거나 지울 수 있다. 장소 discovery와 본편 확인 상태는 별도다.

| 상태 | 표시 | 누르면 |
|---|---|---|
| 발견한 길·장소 | 실제 길 윤곽·장소명·그림 | 설명과 길 방향. 기본 동작은 이동·워프가 아님 |
| 연결은 구현됐고 아직 걷지 않은 길 | 현 위치에서 확인한 입구와 짧은 길 조각만 | 그곳에서 관찰한 단서 한 문장 |
| 아직 듣지 않은 본편 단서 | 숨김 | 전체 이야기·홈·결말을 미리 열지 않음 |
| 다음 질문 선택 | 작은 책갈피 하나 | 해당 단서의 확인한 방향을 표시. 취소·변경 가능 |
| 미구현 공간 | 사용 가능한 길처럼 표시하지 않음 | 막힌 길에 목표를 만들지 않음. 별도 개발 예정 안내는 이야기 단서와 구분 |

첫 추천은 **‘정원 지도판을 살펴볼까?’**, 이후에는 본편 인과에 맞는 질문만 제안한다. 사용자가 다른 길로 가면 팝업으로 되돌리지 않는다. 실제 발견 방향·다음 질문·현실 활동 추천을 하나의 진행도로 합치지 않는다. 전체 지도를 채워야 엔딩을 보는 조건도 없다.


## 감수 기준


- **인과:** 처음의 종이 귀퉁이 → 같은 지형·다른 표시 → 세 지도 비교 → 지도판 재조사 → 홈 발견 → 현재 선택의 실제 표시가 이어져야 한다.
- **플레이:** 모든 필수 장면에서 다음 확인 대상이 보이되, 대화 닫기·보류·산책이 가능해야 한다. 스킵 뒤 수첩에서 해당 장면 재개가 가능해야 한다.
- **선택:** 집 방향·그늘·둘 다·보류의 지도 표현이 구분돼야 한다. 이름을 비워둔 사용자에게 ‘완성했다’고 말하지 않는다.
- **접근:** 미션·구매·씨앗 0회, 모든 선택 보류, 무음 상태에서도 본편을 끝낼 수 있어야 한다. 0회 검수는 캐릭터가 실제로 이동·관찰하는 입력까지 0회라는 뜻이 아니다.
- **지도:** 미발견 장소의 전체 내부·본편 반전을 노출하지 않는다. 미구현 지역을 다음 목표로 지정하지 않는다. 닫힌 UI·작은 화면에서도 현재 위치와 귀환 안내에 다시 접근할 수 있어야 한다.
- **구현:** 사용자 메모·방문·배치·소유품·현실 수행은 별도 저장한다. 원고와 개정 JSON을 같은 콘텐츠 버전으로 연결하고 지도·저장 동작은 별도 구현한다.

재미·몰입·재방문 증가를 검증한 문서가 아니다. 플레이 확인에서는 사용자가 **지금 할 수 있는 행동**, **다음에 궁금한 것**, **돌아갈 길**을 자신의 말로 설명할 수 있는지 확인한다. 경쟁사·공개 서사 도구의 관찰 사실과 여기 제안한 원고는 별도 리서치 문서에서 구분한다.

분기는 짧게 선택한 뒤 자유 이동·본류로 합류시키되, 고른 표식·관찰 메모·메모 보류는 저장해 후속 반응에 남긴다. 본편 7장면 경로, 선택 심화 전부 보류 경로, 무음 경로, 재접속 경로를 각각 플레이하며 검수한다. 이는 공개 서사 도구의 분기·검수 방식을 우리 구조에 적용한 설계 제안이며 특정 도구를 반드시 도입하라는 뜻은 아니다.
