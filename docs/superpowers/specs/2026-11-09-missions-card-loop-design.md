# 미션 1단계: 카드 루프 (설계)

- 작성: 2026-11-09 · 승인: 사용자(채팅에서 결정 8개와 설계 요약 승인)
- 원본: `docs/missions/틈새정원_미션최종안_2026-11-08.md`(사람용 명세), `docs/missions/틈새정원_90개미션_게임적용데이터_2026-11-08_v2.json`(게임 적용 데이터, schemaVersion 2). 팀이 원본을 고치면 이 설계의 가져오기 스크립트를 다시 돌린다.

## 배경
팀이 일상·학업·업무복귀 각 30개, 6단계 미션 90개와 동작 명세를 확정했다. 지금 앱의 활동(16개, 탭 3개)을 이 흐름으로 바꾼다. 이번 1단계는 **카드 한 장으로 고르고 해내는 루프**까지이고, 직접 만든 미션 편집기와 내 하루 지도(5~6단계)는 다음 단계다.

## 사용자 결정
| 항목 | 결정 |
|---|---|
| 순서 | 주민 고도화를 끝낸 뒤 미션(끝남) |
| 씨앗 | 문서 규칙 그대로: 회차가 끝나면 씨앗 1개, 쉬기는 0개(손실도 없음) |
| 하루 상한 | 마친 회차 하루 3개까지(원칙 "하루 활동 최대 3개" 유지, 씨앗도 하루 최대 3개) |
| 범위 | 카드 루프(영역·장면 선택, 카드 한 장, 자기보고, 회차 씨앗, 단계 전환 묻기, 표지판). 1~4단계 카드 60개가 돈다 |
| 여력 체크 | 유지. "조금 무거워요"면 카드의 줄인 행동을 먼저 보여 준다 |
| 기존 활동 화면 | 새 카드 흐름으로 바꾼다. 지금의 "하루 설계"(직접 적기)는 "내가 직접 만들래"로 남겨 첫날부터 쓴다 |
| 영역 선택 위치 | 프롤로그 끝(느리 소개 뒤). 건너뛰면 처음 활동을 열 때 묻는다 |
| 5~6단계 | 추천하지 않는다(4단계까지). 4단계를 넘어서면 "여기서 더 해 볼래 / 다른 영역 / 직접 만들래" |

## 하지 않는 것(이번)
- 5~6단계: 미션 편집기, 내 하루 지도(D21~30·A21~30·W21~30). 데이터는 가져오지만 추천에서 뺀다.
- 조건 키(36개) 설문. 문서대로 처음에 묻지 않는다.
- 표지판 문장을 직접 고쳐 쓰기(이번엔 제안된 다음 행동을 남기거나 건너뛰기만).
- AI·서버.

## 데이터
- `tools/import_missions.py`: 원본 JSON을 읽어 게임에 필요한 칸만 `src/core/data/missions.json`으로 쓴다.
  가져오는 칸: `id, categoryId, stage, stageName, intentIds, npc, dialogue, name, basic, small, completion.buttonLabel, record, smallRecord, conditionSummary, eligibility(allowedWorkStatuses·basicRequiredFacts·smallRequiredFacts), mode, recommendation.nominalNextId`, 그리고 원본의 `firstRecommendations`.
  (`done`은 가져오지 않는다: 일상은 "기본 / 축소" 짧은 말이지만 학업·업무는 설명 문장이라 버튼에 쓸 수 없다. 영역 이름은 `categoryId`로 충분해 `category`도 뺐다.)
  `evidenceCodes·why`처럼 화면에 쓰지 않는 칸은 뺀다(원본에는 남는다).
- 검사(테스트): 90개, 영역 30개씩, 단계 15개씩, ID 겹침 없음, 다음 ID가 모두 있음, 화면에 나오는 글에 금지어 없음.
- 주민 이름 `느리·모루·피오·새싹이`를 `nuri·moru·pio·sprout`로 바꿔 둔다.

## 상태 (`AppState`에 추가)
```ts
type CategoryId = 'daily' | 'academic' | 'work';
interface MissionState {
  category: CategoryId | null;            // 오늘의 영역(언제든 바꿈)
  intents: Partial<Record<CategoryId, string>>; // 영역별 장면
  workStatus: 'pre_return' | 'returned' | 'unknown';
  stage: Record<CategoryId, number>;      // 추천 단계 1~4. 사용자가 "다음 길"을 고를 때만 오른다
  skip: { date: string; facts: string[]; cards: string[] }; // "해당 없어요"(그날만)
  session: { id: string; date: string; actions: { missionId: string; variant: 'basic' | 'small' }[] } | null;
  bookmarks: Partial<Record<CategoryId, { missionId: string; variant: 'basic' | 'small' }>>;
  last: Partial<Record<CategoryId, string>>; // 영역별 마지막으로 한 카드
}
```
- `DayInfo.sessions?: number` — 그날 마친 회차 수(상한 3과 나무 다시 맺기 계산).
- `AppState.sessionPackets: number` — 회차로 받은, 아직 안 연 씨앗 주머니.
- `LogEntry`에 `missionId?`, `variant?`, `sessionId?`. 기록 문장은 카드의 `record`/`smallRecord`.
- 예전 저장본: 위 칸이 없으면 기본값. 예전 활동 기록(`activityId`)은 그대로 보여 준다(옛 활동 16개는 기록 표시에만 남긴다).

## 규칙 (`core/missions.ts`, 순수 함수 · 테스트 먼저)
- **후보 거르기**(문서 0.6 순서): 같은 영역 → 장면이 맞거나 `intentIds`에 `all` → 업무복귀 W06~W20은 `workStatus = returned`일 때만 → 기본·축소마다 `notApplicable`에 걸리는 조건이 있으면 그 버전 제외(둘 다 걸리면 카드 제외) → 단계 4 이하.
- **첫 카드**: 원본 `firstRecommendations` 표(영역·장면 → 카드). 장면을 건너뛴 일상은 D01·D03·D05 미리보기 중 고르기.
- **더 해 볼래**: 줄인 행동만 했으면 같은 카드의 기본 행동. 기본을 했으면 `nominalNextId`를 따라가며 거르기를 통과하는 첫 카드. 그 카드의 단계가 지금 추천 단계보다 높으면 "다음 길을 볼래 / 여기서 더 해 볼래"를 먼저 묻는다.
- **다른 걸 할래**: 같은 영역·장면·단계에서 거르기를 통과하는 다른 카드 최대 2개. 없으면 이전 단계 카드·직접 만들래·영역 바꾸기.
- **회차와 씨앗**(문서 0.7): 카드를 고르면 회차가 없을 때 새로 연다. [했어]마다 행동을 회차에 더하고 기록을 남긴다. [여기까지]면 회차를 닫으며 행동이 1개 이상이고 아직 안 줬으면 씨앗 1개(`sessionPackets += 1`, `days[오늘].sessions += 1`). 행동이 없으면 씨앗 없이 건너뛴 것으로 닫는다. 같은 회차를 두 번 닫아도 씨앗은 한 번.
- **하루 상한**: 오늘 마친 회차가 3개면 새 회차를 열지 않고 "오늘은 여기까지 해도 충분해요".
- **쉬기**: 행동이 있는 회차가 열려 있으면 그 회차를 먼저 정상으로 닫고(씨앗 1개) 쉰다. 없으면 씨앗 없이 쉰다. 쉬는 날 표시(`rested`)는 그대로.
- **표지판**: [여기까지] 뒤 "다음에 이어갈 작은 행동"을 제안한다. 줄인 행동만 했으면 같은 카드의 기본, 기본을 했으면 다음 후보 카드의 줄인 행동. [남기기]/[건너뛰기]. 다시 왔을 때 그 영역의 표지판이 있으면 그 카드부터(조건을 다시 거른다).
- **여력 체크**: 오늘 "조금 무거워요"면 카드에서 줄인 행동을 먼저(위쪽·강조) 보여 준다. 고르는 건 사용자.
- **나무 다시 맺기**: 지금은 "주머니를 받은 날"을 센다. 쉬기에 씨앗이 없어져도 쉬는 날이 손해가 되지 않게, 회차를 마친 날·쉬는 날·예전 주머니를 받은 날을 모두 센다.

## 화면 (`src/ui`)
1. **영역 고르기**(`AreaPick`): 프롤로그 끝, 그리고 영역 없이 활동을 열 때. 느리 "오늘은 어떤 쪽에 한 걸음 남겨 볼까?" [일상] [학업] [업무복귀] [정원 먼저 둘러보기]. 업무복귀면 한 번 [복귀 전] [복귀 후]. 영역 고르기엔 씨앗이 없다.
2. **장면 고르기**(`ScenePick`): 영역의 장면 목록(원본 첫 미션 표). [미리보기에서 고르기]도 둔다.
3. **카드**(`MissionCard`): 주민 얼굴·대사, 미션 이름, 조건 요약(작게), 두 버튼 [이만큼 할래: 기본 행동] [더 작게 할래: 줄인 행동], 아래 [다른 걸 할래] [오늘은 쉴래], 링크 "해당 없어요"·"영역 바꾸기"·"내가 직접 만들래".
4. **정원 위 카드**(`Hud` 활동 카드): 고른 행동과 [했어](`completion.buttonLabel`), [다른 걸 할래].
5. **했어 다음**(`Reflect`를 넓힌다): 지금의 회고 칩(건너뛰기 가능) + [여기까지] [더 해 볼래].
6. **단계 전환**: "다음 길을 볼래? / 여기서 더 해 볼래" (모루).
7. **표지판**: "다음엔 ○○부터 이어 볼까?" [남기기] [건너뛰기] (피오).
8. **내가 직접 만들래**: 지금 "하루 설계" 탭 내용을 단독 패널로 옮긴다. 세운 계획을 해내면 같은 회차 규칙(씨앗 1개)을 따른다.

## 바뀌는 기존 기능
- `ActivityPanel`(탭 3개) → 카드 흐름. "일상 연결" 탭은 없앤다(표지판·다른 걸 할래가 대신한다).
- 이야기 장면의 이어짐: `activity` → 카드 흐름, `daily`(지난 활동 다시) → 표지판 또는 그 영역의 마지막 카드, `design` → 내가 직접 만들래, `plan` → 지금 세운 계획.
- `flow.complete` → 회차에 행동 더하기. 씨앗은 [여기까지]에서.
- 씨앗 주머니 창: `sessionPackets`를 새 출처로 연다(날짜 주머니와 같은 확률).
- 사실 문장(`stats`): 카드 기록 기준으로 "이번 주 ○○ n번째예요".
- 데모 [샘플 채우기]: 미션 카드로 만든다.
- 문구는 `copy.ts`(화면 안내). 카드 내용은 데이터 파일. 금지어 검사는 둘 다.

## 확인 (인수 기준: 원본 0.8에서 이번 범위)
- 첫 접속 후 정원 먼저 → 영역·미션 없이 정원·이야기 이용.
- 일상에서 장면을 건너뛰면 D05를 강제하지 않고 D01·D03·D05 중 고르기.
- 음료(D01) 기본 후 더 해 볼래 → D02가 아니라 D06을 다음 길 후보로.
- 복귀 전에는 W06~W20을 제안하지 않음.
- 기본·축소·다음 카드를 한 회차에 해도 씨앗 1개, 닫기를 두 번 눌러도 1개.
- 행동 후 쉬기 → 그 회차는 정상 정산 후 쉼. 행동 없이 쉬기 → 씨앗 없음.
- 마친 회차 3개면 새 회차 없음.
- 오래 쉬고 와도 단계·식물·기록 유지, 표지판이 있으면 그 카드부터.
- 미션을 하지 않아도 이야기·엔딩이 막히지 않음.
- 테스트: 데이터 검사, 위 시나리오의 규칙 테스트, `npm run build`, 헤드리스 화면 확인. 실제 폰 확인은 사람이.

## 구현하며 구체화한 점(2026-11-09 계획)
계획: `docs/superpowers/plans/2026-11-09-missions-card-loop.md`

1. 장면은 영역별로 기억한다: `intent: string | null` 대신 `intents: Partial<Record<CategoryId, string>>`. 영역을 바꿨다 돌아와도 음료 흐름이 이어진다.
2. "해당 없어요"는 그날만 적용한다: `notApplicable: string[]` 대신 `skip: { date, facts, cards }`. 조건(컵이 있는지 등)은 날마다 바뀌어서, 영구히 빼면 카드가 다시 나오지 않는다. 누른 카드 자체도 그날 뺀다(줄인 행동에 조건이 없는 카드도 뺄 수 있게).
3. `done` 칸은 가져오지 않는다. 일상은 "기본 / 축소" 짧은 말이지만 학업·업무는 설명 문장이라 버튼에 쓸 수 없다. 버튼은 `completion.buttonLabel`("했어").
4. 회차의 행동 목록에서 `missionId`는 선택이다(직접 적은 일과 예전 활동도 같은 회차 규칙).
5. "여기서 더 해 볼래"(단계 전환·4단계 끝)는 같은 카드를 다시 보여 준다. 같은 단계의 다른 카드는 그 카드의 [다른 걸 할래]로 간다.
6. 해낸 행동이 있는 회차가 열려 있으면 카드의 [오늘은 쉴래] 자리에 [여기까지]가 나온다. 정원 위 카드는 계획 없이 회차만 열려 있으면 "한 걸음 남겼어요 [더 해 볼래] [여기까지]".
7. 지난 날 열어 둔 회차는 앱을 열 때(또는 다음 계획을 세울 때) 그날 것으로 정산한다(해낸 행동이 있었으면 씨앗은 받는다).
8. 프롤로그 끝 영역 묻기: 첫 선물(봉투 열기·심기)과 여력 체크가 끝나 화면이 비었을 때 한 번. "정원 먼저 둘러보기"를 고르면 다시 묻지 않고, 처음 [미션 해보기]를 누를 때 묻는다.
9. 일상 장면을 건너뛰면(미리보기) 일상의 장면을 지운다(이전 장면이 미리보기를 거르지 않게).
10. 표지판 카드를 고르면 표지판은 쓴 것으로 지운다.

## 위험
- 일정: 시범 배포(11/12 전후)까지 짧다. 태스크마다 동작하는 상태로 끝내 언제든 멈출 수 있게 한다.
- 씨앗이 하루 최대 3개로 늘어 밭(16칸)이 빨리 찬다. 시범에서 확인할 항목.
- 예전 저장본에 진행 중이던 활동 계획(`days[오늘].plan`, 옛 활동)이 있으면 그대로 끝낼 수 있게 둔다.
