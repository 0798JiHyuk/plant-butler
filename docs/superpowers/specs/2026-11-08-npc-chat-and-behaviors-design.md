# 주민 고도화: 대화·기록과 정원 안 행동 (설계)

- 작성: 2026-11-08 · 승인: 사용자(채팅에서 A·B 승인, A의 도움 문구는 뺌)
- 범위: A. 주민과 채팅형 대화 + 기록(AI 없음) → B. 정원 안 행동. A를 먼저 만들고 확인한 뒤 B.

## 배경
- 그린테라피 멘토 미팅에서 "현실 퀘스트 뒤에 무엇이 남는가", "처음의 재미가 사라진 뒤에도 쓸 이유는 무엇인가"라는 질문이 나왔다.
- 사용자는 주민과 친구처럼 짧게 이야기하고, 그 대화를 **판단하지 않고 그대로 기록**하며, 남기고 싶은 문장·기분은 **본인이 골라** 따로 표시하기를 원했다.
- 설계 원칙(`CLAUDE.md`): 앱이 마음 상태를 판정하지 않는다, 기기 밖으로 개인 정보를 보내지 않는다, 칭찬 대신 사실, 금지어 없음.
- 멘토 기관(그린테라피) 상담사 자료의 제안: 자신을 비춰 볼 수 있는 여러 식물을 **고르게** 해서, 식물을 빌려 마음을 안전하게 표현하게 한다.

## A. 대화 + 기록

### 흐름
1. 주민을 누른다(또는 HUD [대화] = 느리).
   - 그날 열린 이야기 장면이 있으면 지금처럼 이야기가 먼저(`nextSceneFor`). 바뀌지 않는다.
   - 없으면 **대화창**(`panels/Chat.tsx`)이 열린다. 지금의 대사 창(`Talk`)을 대신한다.
2. 대화창
   - 첫 말풍선: 주민의 인사. 지금 `Talk`의 상황 대사(씨앗함에 봉투 있음 → 느리, 열매 열림 → 모루)를 먼저, 없으면 그 주민의 평소 대사 중 하나.
   - 아래: 입력칸(자리표시 "느리에게 한마디…", 보내기 버튼), 그 주민의 일 버튼([씨앗함 보기]·[작업대 보기]·[도감 보기], 지금 `talkActions`), [끝내기].
   - 글을 쓰지 않고 읽기만 하고 나가도 된다(아무것도 저장하지 않는다).
3. 보내면
   - 내 말풍선이 쌓이고, 잠깐(약 0.6초) "…" 뒤에 주민이 대답한다.
   - **대답은 주민별 짧은 받아 주는 말을 차례로**(`copy.chat.replies[npc]`). 내용과 상관없이 같은 차례라서 내용을 해석·판정하지 않는다. 같은 대화 안에서는 같은 말이 연달아 나오지 않는다.
   - 말풍선이 많아지면 대화 영역만 안에서 스크롤된다(패널은 372px 안).
4. [끝내기]
   - 내가 한 줄도 안 썼으면 그냥 닫는다.
   - 한 줄이라도 썼으면 **남기기** 화면으로 바뀐다. 주민: "오늘 이야기 중에 따로 남겨 두고 싶은 거 있어?"
     - 내가 쓴 문장을 눌러 **굵게** 표시(다시 누르면 해제).
     - "한 줄 더 적기"(선택).
     - **마음 식물** 고르기(선택): 싹이 나는 식물 / 잎이 조금 마른 식물 / 가지치기가 필요한 식물 / 옆으로 뻗는 식물 / 그대로인 식물. 다시 누르면 해제.
     - [수첩에 남기기](기본) / [이번엔 남기지 않기](대화를 저장하지 않음).
5. 수첩에 **이야기** 탭(기록·이야기·도감·출석)
   - 날짜별 카드: 주민, 마음 식물, 굵게 고른 문장, 한 줄을 먼저 보여 준다.
   - 대화 원문은 접혀 있고 [대화 보기]를 눌러야 펼쳐진다(옆 사람에게 보일 수 있어서).
   - 카드마다 [지우기](확인 한 번 뒤 삭제, 되돌릴 수 없음을 알림).

### 데이터 (`core/types.ts`)
```ts
export type MindPlant = 'sprouting' | 'dry' | 'prune' | 'sideways' | 'steady';
export interface ChatLine { from: 'me' | NpcId; text: string; keep?: boolean }
export interface ChatLog { id: string; date: string; npc: NpcId; lines: ChatLine[]; note?: string; mind?: MindPlant }
// AppState에 추가
chats: ChatLog[];
```
- `loadState`는 예전 저장본에 `chats`가 없으면 `[]`로 채운다(`createState` 기본값 + 기존 병합 방식).
- 기기 안 localStorage에만 있다. 집계·통계(`stats.ts`, 디버그 줄)에 넣지 않는다.

### 규칙 (`core/chat.ts`, 순수 함수 · 테스트 먼저)
- `npcReply(npc, turn)`: 그 주민의 받아 주는 말 중 `turn`번째(돌아가며). 빈 문자열이 없다.
- `canSave(lines)`: 내 말이 한 줄 이상이면 true.
- `saveChat(draft, log)`: 내 말이 없으면 저장하지 않고 false. 공백만 있는 문장은 빼고, 저장 시 `id`를 정한다.
- `deleteChat(draft, id)`: 없는 id면 아무 일 없음.
- 입력 길이 제한: 한 번에 200자(입력칸 `maxLength`), 저장할 때도 자른다.

### 문구 (`core/copy.ts`의 `chat` 묶음)
- 자리표시·버튼·남기기 질문·마음 식물 이름·수첩 탭 이름·지우기 확인.
- 주민별 받아 주는 말 4~5개씩, 스토리 바이블 말투(반말, 짧게). 예: 느리 "그렇구나. 천천히 들었어." / 모루 "알겠어. 수첩에 적어둘게." / 피오 "오, 그랬구나!"
- 금지: 칭찬("대단해"), 마음 추측("힘들었겠다", "우울"), 모든 말을 "괜찮아"로 끝내기, 금지어 목록. `copy.test.ts`가 함수형 문구까지 검사한다.
- 도움 문구(109·1577-0199)는 이번에 넣지 않는다 → 긴급 연결 기능을 만들 때 함께(사용자 결정).

### 화면 제약
- 844×390에서 패널 372px 안, 버튼 44px 이상. 글을 쓰는 동안 Phaser 키보드 가로채기는 지금처럼 모달 경로(`ui-lock`)로 꺼진다.
- **위험**: 가로 폰에서 화상 키보드가 화면의 절반 이상을 가린다. 입력칸을 패널 아래쪽에 두고, 입력 중에는 말풍선 영역을 줄인다. 실제 폰 확인이 필요하다(헤드리스로는 확인 못 함).

## B. 정원 안 행동 (`scene/Npc.ts`, `GardenScene`)

1. **새 이야기 표시**: 그날 열린 이야기 장면이 있는 주민 머리 위(이름표 위)에 작은 말풍선 표시. `GardenScene`이 상태가 바뀔 때·날짜가 바뀔 때 `nextSceneFor`로 계산해 `npc.setMark(on)`. 보고 나면 사라진다(하루 한 장면 규칙 그대로).
2. **다가가면 반응**: 새싹이가 가까이 오면(약 90px) 그쪽을 돌아본다(옆모습을 새싹이 쪽으로). 처음 다가왔을 때 짧은 말풍선 2~3초(스토리 바이블 10장 상황 대사, `copy.npcGreet[npc]`). 같은 주민은 약 1분 동안 다시 말하지 않는다. 창이 열려 있거나 꾸미는 중에는 하지 않는다.
3. **주민마다 다른 버릇**(그림 추가 없이 움직임으로)
   - 느리: 더 느리게 걷고(약 12px/초) 오래 멈추며, 멈춰 있을 때 고개를 기울이듯 살짝 기울어진다.
   - 모루: 멈춰 있을 때 망치질하듯 짧게 두 번 들썩인다.
   - 피오: 걸을 때 통통 뛰듯 움직인다.
   - 위치(x, y)는 바꾸지 않고 그리는 기준점·기울기·크기만 움직인다(충돌·앞뒤 판단에 영향 없음).
4. **쉬는 날엔 같이 쉬기**: 오늘 "쉬기"를 고른 날은 주민이 자기 자리 근처에서 거의 움직이지 않고 천천히 숨쉬듯 움직인다. 다가가면 쉬는 말(스토리 바이블 "활동 미실행" 대사, 예: 피오 "그럼 나도 잠깐 조용히 있어볼래.")을 한다.

## 이번에 하지 않는 것
- AI 대답(서버·API·사용료·동의 화면·위기 대응이 먼저 정해져야 함). 나중에 `npcReply`만 바꿔 끼운다.
- 도움 문구(긴급 연결과 함께).
- 마음 식물을 골랐을 때 그에 맞는 활동 추천(나중 후보).
- 주민 새 그림(앉기·눕기 포즈 등).

## 확인 방법
- `npm test`: 대화 규칙(대답 차례, 저장 조건, 삭제, 길이 제한), 예전 저장본 불러오기, 문구 금지어.
- `npm run build` 후 `tools/screenshot.mjs`: 주민 누르기 → 대화창 → 글 보내기 → 끝내기 → 남기기(굵게·한 줄·마음 식물) → 수첩 이야기 탭 → 펼치기·지우기. B는 표시·말풍선·쉬는 날 모습 캡처.
- 실제 폰에서 키보드가 올라온 상태의 대화창 확인(사람 확인 필요).
