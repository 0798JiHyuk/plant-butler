# 앱에 들어간 이야기 장면

원본은 팀 스토리 바이블 《틈새정원》이다. 대사는 `src/core/data/story.json`에 있고, 언제 열리는지는 `src/core/story.ts`가 정한다. 대본을 고칠 때는 이 문서의 "바꾼 대사"와 "뺀 부분"도 함께 확인해 주세요.

## 언제 나오나
| 장면 | 나오는 때 |
|---|---|
| 프롤로그 P01~P03 (`intro`) | 처음 앱을 열 때 한 번 |
| 본편 A01 → B01 → B02 → C01 → C02 → D01 → E01 | 해당 주민을 누르면 순서대로 열린다. A01은 느리, B는 모루, C는 피오, D·E는 아무 주민. 앞 장면을 봐야 다음이 열린다. 씨앗·열매·구매 같은 경제 상태로는 잠그지 않는다 |
| 서브 S01~S06 | 그 주민의 본편을 다 본 뒤 그 주민을 누르면 열린다(느리 S01·S02, 모루 S03·S04, 피오 S05·S06) |
| 주민 이야기 공통 | 본편과 서브를 합쳐 **하루에 한 장면**. 열린 장면이 없으면 평소 대사가 나온다. 데모 모드에서는 하루 제한이 없다 |
| 복귀 R01·R02·R03·R06·R07·R10 | 마지막으로 활동을 완료하거나 쉬기를 고른 날부터 2일 이상 지나 앱을 열면, 여력 체크보다 먼저 하나가 나온다(하루 한 번). 우선순위는 R02 지난 계획 → R03 마지막이 직접 계획 → R07 안 연 봉투·씨앗 → R06 딸 수 있는 열매 → R10 선물함 → R01. 며칠 비었는지는 말하지 않는다 |

## 바꾼 대사
| 장면 | 원문 | 앱 | 이유 |
|---|---|---|---|
| B02-02 | "고치면 처음부터 **잘못했다는** 뜻인 줄" | "고치면 처음부터 **틀렸다는** 뜻인 줄" | 금지어 검사의 "못했"에 걸림. 뜻은 같음 |
| D01-01·02, E01-01·08 | 지문(설명) | 새싹이 말풍선으로 표시 | 화면에 해설자 칸이 없음 |
| D01-10A | "그 이름은 네가 고른 거야. 바꾸고 싶으면 연필이 여기 있어." | "좋아. 연필은 여기 둘게. 이름은 천천히 정해도 돼." | 이름 입력창이 아직 없어 이름을 고른 것처럼 말하면 안 됨 |
| R01 | "저번에 놓은 풍경이 아직 여기 있어." | 소품이 있으면 원문, 식물만 있으면 "저번에 심은 식물이 여기 있네.", 둘 다 없으면 "저 나무는 여전히 그 자리에 있네." | 실제로 놓은 게 있을 때만 "놓은"이라고 말한다(바이블 연속성 규칙 3) |
| R02 선택지 | 더 작게 / 다른 활동 / 다음에 / 계획 지우기 / 정원 구경 | 오늘 그대로 보기 / 다른 활동 고르기 / 계획 지우기 / 다음에 | 한 화면에 4개까지. "더 작게"는 계획 상세 화면에서 할 수 있음 |
| E01 끝 | 조건 10·11·12 | 씨앗 → 10, 열매 → 11, 식물 있음 → "저 나무는 여전히 그 자리에 있네.", 아무것도 없음 → 12 | 식물은 있지만 씨앗·열매가 없는 경우의 대사가 원본에 없음 |

## 뺀 부분
- **소품 보상**: 바람 고리(A01-03·04), 조약돌, 지우개 연필, 삐뚤어진 의자, 표지판, 음표, 벤치 이름표. 그림이 없고, "놓았구나"는 실제로 배치한 뒤에만 쓸 수 있다. 그림이 생기면 선택지와 함께 다시 넣는다.
- **A02·A03·B03·C03**: 활동 완료, 씨앗 열기, 상점, 도감 흐름에 상황 대사(`copy.lines`)로 이미 들어가 있다.
- **B02-03**: 길 표시를 바꿀 때 달라지는 모루 대사. 지도판 표시 기능이 아직 없다.
- **D01 "내 지도 이름 짓기"**: 이름 입력·저장 기능이 없다. 선택만 기억한다.
- **R04 기록 삭제**: 실제 삭제는 개인정보 검토가 필요하다.
- **R05 도움받기**: 긴급 연결 화면을 만들 때 함께 넣는다.
- **R08·R09**: 씨앗 중복과 열매 부족 상황은 상황 대사로 처리한다.

## 선택이 바꾸는 것
- C02와 S05의 선택지, 복귀 장면의 선택지는 활동 화면(추천·일상 연결·하루 설계), 씨앗함, 선물함으로 이어진다.
- C02 "오늘은 그냥 쉴래"와 R03 "쉬기"는 실제로 오늘을 쉬는 날로 남긴다(앱의 쉬기와 같다).
- R02 "오늘 그대로 보기"는 지난 계획을 오늘로 옮기고, "계획 지우기"는 지운다.
- 나머지 선택은 기억만 한다(`story.choices`). 지도판 기능이 생기면 이 값을 읽는다.
